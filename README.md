# WebScraper – сбор данных с веб-ресурсов

**Автор:** Александр Казин  
**Лицензия:** MIT

## Описание
Консольное приложение на C# для сбора (парсинга) данных с веб-сайтов.  
Проект демонстрирует работу с HTTP-запросами, парсинг HTML с помощью библиотеки HtmlAgilityPack и управление версиями Git.

## Технологии
- .NET 6 / .NET 8
- C# 10
- HtmlAgilityPack

## Установка и запуск
1. Установите .NET SDK (6.0 или новее) с [dotnet.microsoft.com](https://dotnet.microsoft.com/download)
2. Клонируйте репозиторий:  
   `git clone https://github.com/AlexandrKazin/WebScraper.git`
3. Перейдите в папку проекта:  
   `cd WebScraper`
4. Восстановите зависимости:  
   `dotnet restore`
5. Запустите приложение:  
   `dotnet run -- --url "https://example.com/news"`

## Пример использования
После запуска программа выводит заголовки новостей с указанного URL в консоль.
